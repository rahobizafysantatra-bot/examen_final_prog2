# Account Transaction API

A Spring Boot REST API generated from the supplied UML model. Data access uses raw JDBC with `DriverManager`, `PreparedStatement`, and try-with-resources. JPA and `JdbcTemplate` are not used.

## Technical choices

- Java 17
- Spring Boot 3.5.16
- PostgreSQL
- Lombok models and DTOs without setters
- Constructor-based dependency injection
- A mandatory `account_id` foreign key represents the UML `Account 1..1 -> 0..* Transaction` relation
- `Account` contains an immutable transaction list returned by the repository
- `TransactionCreateDto` is used only for POST input because `id` and `createdAt` are generated by the server
- API output uses the full `Transaction` entity because it has no heavy nested collection

## Database setup

Create a PostgreSQL database named `account_transaction_db`, then execute:

```bash
psql -U postgres -d account_transaction_db -f src/main/resources/database.sql
```

Default connection settings are in `src/main/resources/application.yml`. They can be overridden with:

```bash
export DB_URL=jdbc:postgresql://localhost:5432/account_transaction_db
export DB_USERNAME=postgres
export DB_PASSWORD=postgres
```

## Run

```bash
mvn spring-boot:run
```

## Endpoints

### Filter transactions by type

```bash
curl "http://localhost:8080/transactions?type=in"
curl "http://localhost:8080/transactions?type=out"
```

### Get all transactions for an account

```bash
curl "http://localhost:8080/accounts/account-standard-001/transactions"
```

### Create a transaction

```bash
curl -X POST "http://localhost:8080/transactions" \
  -H "Content-Type: application/json" \
  -d '{
    "accountId": "account-standard-001",
    "transactionType": "out",
    "amount": 35.50,
    "reason": "Office supplies"
  }'
```

### Calculate an account balance

```bash
curl "http://localhost:8080/accounts/account-standard-001/balance"
```

The balance is calculated as the sum of `IN` amounts minus the sum of `OUT` amounts.
